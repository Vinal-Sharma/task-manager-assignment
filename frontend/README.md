# Task Manager App

## Features

- User Registration
- User Login with JWT
- Create Tasks
- Update Task Status
- Delete Tasks
- Three Stages:
  - Todo
  - In Progress
  - Done

## Tech Stack

Frontend:
- React
- Axios
- CSS

Backend:
- Node.js
- Express.js
- MongoDB Atlas
- JWT
- bcryptjs

## Assumptions

- Tasks are shared globally.
- Authentication is implemented through JWT tokens.
- Basic task management workflow.

## Setup

### Backend

npm install
node server.js

### Frontend

npm install
npm run dev
